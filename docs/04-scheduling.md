# 04 · 复习调度契约

> 依据 ADR-009（SM-2 起步）、ADR-002（双轨播种）。约束 `RepetitionState`（`01`）。
> 结论先行：**算法二选一，本包选 SM-2**；FSRS 字段若保留仅供展示，不得与 SM-2 混算。

## 一、算法声明（INV-31）

`RepetitionState` 现同时存在两套字段，必须显式声明用哪套：

| 字段 | 归属 |
| --- | --- |
| `interval_index`、`consecutive_correct/wrong`、`ease_factor` | **SM-2（本包采用）** |
| `difficulty`、`stability`、`retrievability`、`desired_retention` | FSRS（本包**不参与计算**；`difficulty` 仅展示或删除） |

- 若最终改用 FSRS：需另立 ADR，并把 SM-2 字段移除；不得两套并用。

## 二、SM-2 具体实现

### 1. 评分映射（把证据转成 q∈0..5）
| 我们的结果 | q |
| --- | --- |
| 独立答对、无提示 | 5 |
| 独立答对、用时偏长 | 4 |
| 有提示答对 / `partial` | 3 |
| 答错 | 0 |

concept/design 的定性通过 = 视为 `q=4`；不通过 = `q=0`。

### 2. 易度因子 EF
```
EF' = EF + (0.1 - (5-q)*(0.08 + (5-q)*0.02))，下限 1.3
EF₀ = 2.5
```

### 3. 间隔序列
```
I(1) = 1 天
I(2) = 6 天
I(n) = round(I(n-1) * EF)      n > 2
```

worked example（EF=2.5，一路 q=5）：

| 第 n 次 | 间隔 |
| --- | --- |
| 1 | 1 天 |
| 2 | 6 天 |
| 3 | 15 天 |
| 4 | 38 天 |
| 5 | 95 天 |

## 三、failure 后间隔

- **SM-2 原版**：`q<3` → 重复次数 `n` 重置为 0，`EF` 按公式下调，下次间隔**回到 1 天**。
- **本包采用（贴近 Anki）**：失败进入**重学步**——当天 10 分钟 → 次日 1 天 → 再按序列回升；`lapse_count += 1`。
- 失败**只重置间隔进度**；"这题很难"的信息由下调后的 EF 保留。

## 四、`scheduled_after_failure` 的语义与重置（INV-30）

它标记：**当前 `next_review_at` 这个锚点，是否由失败响应产生**（与 `last_scheduled_at` 构成"锚点来源"）。

| 事件 | 标志 |
| --- | --- |
| 失败 → 设置新 `next_review_at` | 置 **True** |
| 下一次**正式复习成功**（跨会话，真正设置新锚点） | 置 **False** |
| **会话内**又练一次且答对（只改 `last_review_at`，不动锚点） | **不改**（仍 True） |
| 毕业（`consecutive_correct ≥ 阈值`） | 清零 False |

**为什么"会话内通过不清零"**：锚点语义要求"改目标不能悄悄推迟已到期的复习"；会话内练习不改锚点，就不该改锚点来源，否则"同一天多练几次"会抹掉失败痕迹、掩盖真实遗忘风险。

## 五、播种参数（ADR-002 / INV-19）

系统轨与声明轨初始状态不同（**单调度器，用 provenance 播种**，不写第二套调度器）：

| provenance | 初始 `interval_index` | 首次间隔 | 说明 |
| --- | --- | --- | --- |
| `system` | 0 | 按 SM-2 正常序列（I(1)=1 天） | 有评估证据 |
| `learner` | 0 | **约系统轨 0.5×**（如当天/半日） | 声明无评估证据，先验更保守 |

> 具体数值（`S₀×0.5` 等）**已由产品方确认**（见 `00` §四）。验收：同 KP 声明轨/系统轨首次到期时间之比 ∈ `[0.3, 0.7]`。

## 六、场景预设（二期，MVP 不做）

- **一期不做 `scenario`**：固定 general 档（`desired_retention=0.9` + 双轨播种），先把调度跑对。
- **二期**：`scenario ∈ {interview, vocabulary, mistake_book, general}` 作为**预设**，派生 `desired_retention` 与播种参数；学习者只选预设 + 一个"记多牢"滑块（映射 `desired_retention`，限幅）；**永不暴露 `S₀/D₀/更新公式`**（`INV-19`）。
- **改场景默认只影响新条目**（`INV-20`）；若提供追溯需显式按钮。
- 预设示例（**已确认**）：

| 场景 | desired_retention | 首次间隔(Good) | 首次评分倾向 |
| --- | --- | --- | --- |
| 面试突击 | 0.95 | 1.5–2 天 | 偏 Hard/Good，禁 Easy |
| 背单词 | 0.9 | 3 天 | Easy/Good 严格区分 |
| 错题本 | 0.92–0.93 | 1–2 天 | 偏 Hard，禁 Easy |
| 通用 | 0.9 | 1–6 天（SM-2 序列） | 标准 |

> 注意：`desired_retention` 是 FSRS 概念，**SM-2 不消费它**；上表仅为"若切 FSRS"的预置参考，或用于展示"复习量旋钮"。SM-2 下复习频率由 EF 与间隔序列决定。

## 七、参数语义备查

- `desired_retention`：目标记忆保留率（复习时仍记得的概率）。**FSRS 参数**，非 SM-2 概念（原稿"按 SM-2 惯例"系误标）。区间 `[0.7,0.99]`。
- `difficulty`：条目难度。**FSRS 参数**；SM-2 无此概念。默认 `0.3` 若保留仅供展示。
- 两个 `0.9` 不同义：门槛 `0.9`（是否掌握）≠ `desired_retention 0.9`（复习目标概率）；代码中必须是**两个独立常量**。
